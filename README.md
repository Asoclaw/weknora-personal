# WeKnora 个人知识库

基于 [WeKnora v0.8.2 正式版](https://github.com/Tencent/WeKnora/releases/tag/v0.8.2)，上游发布提交为 `3e8b0bfc80b845b2d4b2ed683994748741450a97`。本项目面向个人使用，可独立运行，供工作台和外部 Agent 使用现有 API 或 MCP 接入。

## 个人功能开放，服务按需启用

- 保留资料管理、搜索问答、Wiki、图谱浏览、图片与音频处理。
- 开放智能体、Skill、MCP、联网搜索、记忆、全部数据源、FAQ、自动标签、存储与检索引擎配置入口，沿用上游的权限和部署能力检查。
- 隐藏组织、成员、邀请、空间切换及组织共享管理入口。底层认证、权限和隔离机制保留。
- 默认只运行前端、后端、DocReader、PostgreSQL 和 Redis。显示入口不会自动启用沙箱、Neo4j、Langfuse、MinIO、本地 Ollama 或其他可选服务。
- 保留简洁登录页面、新建知识库默认开启 Wiki，并修复文档深链接重复打开侧栏和设置面板重复挂载的问题。

## 腾讯文档连接器

新增 `tencent_docs` 类型，复用原有数据源授权、调度、日志、暂停和同步删除机制。支持选择个人版或企业版、选择多个文件夹，默认每天同步，也可立即同步。

企业版同时列出“我的文档”与“共享空间”的文件夹，保留源文件标识和目录路径。更新或移动沿用重新入库机制，已有库内分块修正可能需要重做。可同步格式以实际授权接口能取得的正文为准，无法读取的内容在日志中说明。

v0.8.2 已完成企业版真实授权的目录展开和正文读取验证，以及增量更新、移动和删除检测测试。个人版真实授权及 PDF、图片和内嵌图片的自动读取仍待验证。

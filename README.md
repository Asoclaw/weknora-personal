# WeKnora 个人知识库

这是基于 [WeKnora](https://github.com/Tencent/WeKnora) v0.8.0 发布提交 `1edcd54b` 调整的个人知识库版本。目标是作为独立运行的知识库，供个人工作台通过现有 REST API 调用：直接使用上游成熟能力，停用可选重服务，简化日常界面，只新增腾讯文档数据源。

## 这个版本做了什么

| 范围 | 当前处理 |
| --- | --- |
| 资料管理 | 保留多知识库、文件夹、手动标签、笔记、文件与网址导入，以及原有解析和分块纠错。 |
| 查找与问答 | 保留搜索、带来源的问答、会话历史和库内多步资料整理。 |
| Wiki | 保留自动生成、图谱浏览、人工编辑与版本回滚；新建知识库默认开启 Wiki。未启用 Neo4j 图谱增强检索。 |
| 图片、音频与表格 | 沿用上游的图片文字识别、视觉描述、音频转写、摘要和按需表格分析。 |
| 个人界面 | 隐藏团队、组织、智能体、额外集成、FAQ 等日常不用的入口，以及部分引导和宣传文案；保留模型的高级设置。上游模块仍在源码中，便于后续升级。 |
| 部署 | 仅运行前端、后端、DocReader、PostgreSQL 和 Redis。Neo4j、MinIO、Langfuse、沙箱和本地 Ollama 等可选服务不随个人部署启动。 |
| 数据源 | 保留上游飞书知识库和飞书云盘连接方式；新增 `tencent_docs` 连接器，接入 WeKnora 现有数据源框架。 |

## 腾讯文档连接器

- 可在一个知识库中选择多个文件夹，保留目录路径和稳定的源文件标识。
- 默认每天同步一次，也可手动立即同步；沿用原有同步日志、暂停、增量更新和“同步删除”开关。
- 提供个人版 `docs.qq.com` 和企业版 `saas.docs.qq.com` 两种站点选项。内容更新仍按 WeKnora 原有机制重新入库，因此已做的库内分块修正可能需要重做。
- 仅导入授权接口实际能取得的正文；取不到正文的文件会在同步结果中说明，可改用手动上传。
- 企业版根目录同时列出“我的文档”和“共享空间”的文件夹；共享项目文件夹可继续展开选择。

**验证状态：**企业版授权已在隔离环境完成只读连接、导入、检索和重复同步验证。个人版授权、PDF、图片及文档内图片的读取能力尚未通过真实账号验证，不承诺这些格式已可自动同步。

## 运行和资料边界

构建、镜像与 Docker 配置见 [个人版构建说明](PERSONAL_README.md) 和 [`personal/`](personal/)。模型与访问凭证由本地环境配置提供。仓库只同步功能代码，不包含个人资料、数据库、文件卷、备份或令牌。

这是独立维护的个人版本，并非腾讯官方发布版。原项目的完整功能、部署方式和文档请参阅 [WeKnora 官方仓库](https://github.com/Tencent/WeKnora)；源码沿用其 [MIT 许可证](LICENSE)。

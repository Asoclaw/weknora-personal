# WeKnora 个人知识库

基于 [WeKnora v0.8.2 正式版](https://github.com/Tencent/WeKnora/releases/tag/v0.8.2)，上游发布提交为 `3e8b0bfc80b845b2d4b2ed683994748741450a97`。本项目面向个人使用，可独立运行，供工作台和外部 Agent 使用现有 API 或 MCP 接入。

## 个人功能开放，服务按需启用

- 保留资料管理、搜索问答、Wiki、图谱浏览、图片与音频处理。
- 开放智能体、Skill、MCP、联网搜索、记忆、全部数据源、FAQ、自动标签、存储与检索引擎配置入口，沿用上游的权限和部署能力检查。
- 隐藏组织、成员、邀请、空间切换及组织共享管理入口。底层认证、权限和隔离机制保留。
- 默认只运行前端、后端、DocReader、PostgreSQL 和 Redis。显示入口不会自动启用沙箱、Neo4j、Langfuse、MinIO、本地 Ollama 或其他可选服务。
- 保留简洁登录页面、新建知识库默认开启 Wiki，并修复文档深链接重复打开侧栏和设置面板重复挂载的问题。

## 腾讯文档连接器

新增 `tencent_docs` 类型，复用原有数据源授权、调度、日志、暂停和同步删除机制。支持个人版或企业版、多个文件夹及单个文件选择，默认每天同步，也可立即同步。

企业版保留源文件标识、目录路径和原文链接，优先按DOCX、XLSX、PPTX等原格式入库；无法下载但能取得有效正文时使用Markdown兜底。内容未变时保留资料ID、片段、Wiki及关联；补链接、标题或目录变化只更新必要信息。源内容真实变化时才更新对应内容及受影响关联。

已完成企业版真实授权的目录、原格式入库、正文检索、原文及图片读取验证。个人版腾讯文档须由使用者独立授权验证；可同步内容以实际接口能力为准。

## 摹客连接器与文件浏览

- 摹客使用页面配置的服务地址和账号密码，登录后发现团队，支持多选项目及递归画板分组。优先同步当前画板图片，有有效文字时使用Markdown兜底。
- 同一知识库按数据源展示目录，支持子目录导航、累计文件数、目录宽度调整、具体扩展名多选、图片缩略图和连续预览。

## 解析与同步稳定性

固定并发和内存保护，表格分批读取和向量化，兼容异常Excel样式；DNS有界重试且不缓存失败。图片任务完成计数幂等，未完成表格从既有片段继续处理。恢复工具位于`cmd/parse-recovery`，仅供备份后的管理员定点操作，不自动重建资料。
